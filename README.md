Zomato Restaurant & Order Analysis | Power BI

Project Overview
This project presents an interactive Zomato Restaurant & Order Analysis dashboard built using Power BI.

The project focuses on cleaning and transforming restaurant and order data, building a structured data model, creating DAX measures, and developing interactive visualizations to analyze restaurant and order performance.

Data Model
The Power BI model follows a structured fact-and-dimension approach using:
Fact_Orders
Dim_Restaurant
Dim_Date
The Calendar table enables time-based analysis of orders and revenue.

Project Objective
The objective of this project is to transform raw restaurant and order data into an interactive Power BI dashboard that supports data-driven analysis and makes key business trends easier to understand.
