**Zomato Restaurant & Order Analysis**

**Project Overview**

This project is an interactive Power BI dashboard developed using Zomato restaurant and order data to analyze revenue performance, order trends, restaurant performance, customer ratings, delivery time, city-wise distribution, and pricing patterns.

The project follows an end-to-end data analytics workflow, including data cleaning, transformation, data modeling, Calendar table creation, DAX measures, KPI development, and interactive dashboard design.

**Data Model**

The Power BI model follows a structured fact-and-dimension approach:
•	Fact_Orders – Order transaction data
•	Dim_Restaurant – Restaurant information
•	Dim_Date – Calendar table for time-based analysis
The model establishes relationships between the restaurant, order, and date tables to support interactive filtering and analysis.

**Key Insights**

•	Mumbai contributes the highest share of total orders at approximately 23.5%.
•	Mumbai records 235 orders across 115 restaurants.
•	Restaurant_56 is the highest-revenue restaurant in the dashboard, generating approximately ₹10K.
