Zomato Restaurant & Order Analysis | Power BI
📌 Project Overview
This project presents an interactive Zomato Restaurant & Order Analysis Dashboard developed using Power BI.

The project focuses on cleaning and transforming restaurant and order data, building a structured data model, creating DAX measures, and developing interactive visualizations to analyze restaurant and order performance.

🗂️ Data Model
The Power BI model follows a fact-and-dimension approach using:

Fact_Orders – Order transaction data
Dim_Restaurant – Restaurant information
Dim_Date – Calendar table for time-based analysis
The Calendar table enables analysis of revenue and orders across different time periods.

💡 Key Insights
Mumbai contributes the highest share of total orders at approximately 23.5%.
Mumbai records 235 orders across 115 restaurants.
Restaurant_56 is the highest-revenue restaurant in the dashboard, generating approximately ₹10K.
Average restaurant ratings are similar across price ranges, with High and Medium at approximately 3.8 and Low at 3.7.
Revenue shows noticeable variation across months rather than remaining constant throughout the year.
